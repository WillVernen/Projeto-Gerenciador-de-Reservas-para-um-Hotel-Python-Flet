# Projeto de um Sistema para Gerenciar as Reservas de um Hotel

## Tecnologias: Python e Flet

### Como usar:
- Para usar, ir na aba `app_flet.py` e executar. 

### Objetivos:
- Gerenciar reservas de quartos em um hotel
  * Adicionar Quarto
  * Registrar Cliente
  * Listar Quartos Disponíveis
  * Fazer Reserva
  * Cancelar Reserva

### Melhorias Futuras:
- Calendário de Disponibilidade: Melhorar nossa lógica de disponibilidade para usar datas
- Relatórios e Estatísticas: Gerar um relatório simples de ocupação
- Gerenciamento de Clientes: Manter um histórico de reservas por cliente
